Bitácora de Diseño UX - Actividad 1

Proyecto: MapStar - EcoRutas Tijuana
Fecha: 27 de Enero, 2026

1. Selección del Nicho y Propuesta de Valor

Se eligió el nicho de "EcoRutas y Seguridad Urbana" para la ciudad de Tijuana.

Problema: Los usuarios quieren explorar la ciudad pero temen por la seguridad o la contaminación.

Solución (MapStar): Un mapa que prioriza rutas verdes, iluminadas y verificadas por la comunidad.

2. Decisiones de Diseño (Landing Page)

A. Heurísticas de Nielsen Aplicadas

Correspondencia entre el sistema y el mundo real: * Se utilizó una metáfora visual de mapas topográficos en el fondo (líneas de elevación sutiles) para que el usuario entienda inmediatamente que es una app de geolocalización sin necesidad de leer.

Iconos universales: Se usaron iconos de Lucide familiares como la brújula (exploración), el escudo (seguridad) y la hoja (naturaleza).

B. Psicología del Color y Estética

Modo Oscuro (Dark Mode): Se eligió un fondo slate-900 por dos razones UX:

Evoca "aventura nocturna" y sofisticación.

Reduce el consumo de batería en dispositivos móviles (OLED), crucial para apps de senderismo.

Acentos de Color:

Verde Esmeralda (emerald-500): Para denotar "Eco", naturaleza y permiso/seguridad (semáforo verde).

Naranja/Ámbar (amber-500): Usado para alertas y seguridad, creando contraste para llamar la atención sobre elementos importantes.

C. Jerarquía Visual y CTA

El botón "Explorar Mapa" es el elemento más prominente (Ley de Fitts). Se le dio un tamaño grande, un color de contraste alto y una sombra brillante (shadow-emerald-900) para invitar al clic inmediato.

3. Registro de Prompts (IA)

Prompt Principal utilizado:

"Actua como disenador web, requiero que crees una Landing Page HTML para una app de mapas llamada MapStar, enfocada en ecoRutas para la ciudad de Tijuana. Debe tener un 'Hero' con una imagen de fondo de un mapa estilizado o topográfico, un título grande, y un botón CTA prominente que diga 'Explorar Mapa'. Usa Tailwind CSS. El diseño debe inspirar aventura/seguridad y sobre todo debe de ser atractivo para el usuario, ademas de ser responsivo para cualquier tipo de dispositivo."

Refinamiento:

Se solicitó explícitamente el cambio de una imagen que estaba rota ("Hiking map view") por una de naturaleza visible para mantener la inmersión.

Se solicito volver responsiva la landing page.
